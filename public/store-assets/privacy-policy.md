# Privacy Policy

Stellaris Local Assist processes the user's selected text, current page title, and current page URL only after the user explicitly invokes the extension on an approved site.

- All generation requests are sent only to a loopback Ollama endpoint on the same machine.
- The extension does not transmit prompts, generated text, browsing data, or usage analytics to any remote service.
- The extension stores only local configuration data: Ollama endpoint, selected model, custom actions, and granted-site display labels.
- Users can revoke site access from Chrome or from the extension options page at any time.

The extension is designed for local-only use and rejects non-loopback model endpoints.
